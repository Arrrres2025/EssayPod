# Contributing to EssayPod

Thank you for helping improve EssayPod.

## Development setup

1. Fork the repository and clone your fork.
2. Follow the installation instructions in `README.md`.
3. Create a branch for each change:

   ```bash
   git switch -c feature/short-description
   ```

4. Keep secrets, uploaded papers, generated audio/video, and runtime data out
   of commits. The root `.gitignore` covers the standard locations.
5. Run the relevant Python tests and the Web UI checks before opening a pull
   request.

## Pull requests

- Explain the problem and the approach taken.
- Keep unrelated changes in separate pull requests.
- Include screenshots for visible UI changes.
- Mention any new environment variables or dependencies.
- Do not include copyrighted papers or credentials in fixtures.

By contributing, you agree that your contribution is licensed under the
repository's AGPL-3.0-or-later license.
