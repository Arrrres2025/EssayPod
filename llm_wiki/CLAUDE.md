# LLM Wiki Maintainer

The canonical schema and operating instructions for this repository are in
`AGENTS.md`. Read and follow that file in full before ingesting, querying, or
maintaining this wiki.

This alias exists because Karpathy's pattern names `CLAUDE.md` as the schema
entry point for Claude Code; Codex uses `AGENTS.md`. Both agents therefore share
one source of operational truth rather than two drifting copies.
